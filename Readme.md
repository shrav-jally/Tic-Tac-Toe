# 🎮 Tic Tac Toe Game

A simple browser-based **Tic Tac Toe** game made with **HTML**, **CSS**, and **JavaScript**.

---

## 🚀 Features

- Two-player mode (Player O vs Player X)
- Displays the winner
- Reset & New Game buttons
- Fully interactive 3x3 game grid

---

## 🧠 Game Logic (JavaScript)

- The game board is a 3x3 grid made of buttons.
- Players take turns clicking on empty boxes.
- Player O starts first, followed by Player X.
- After each move, the game checks for a winner using a list of winning patterns.
- If a player wins, a message is shown and all boxes are disabled.
- Players can restart or reset the game at any time.
